# АвіаПром ERP/PLM (Варіант № 6)

**Призначення:** Програмна система управління процесами на авіабудівельному підприємстві (конструкторсько-технологічна підготовка CAD/BOM, складський облік RFID та диспетчеризація складання вузлів).

## Функціональність
- Управління ревізіями креслень (CAD) та специфікаціями (BOM)
- Швидкий індексований пошук комплектуючих за серійним номером (< 1.5 с)
- Валідація RFID-міток та сертифікатів якості перед видачею у цех
- Експорт звітів готовності вузлів у PDF

## Технології
Node.js 20, PostgreSQL 16, Redis 7, Git, GitHub Actions
